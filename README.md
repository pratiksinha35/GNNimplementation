# Molecular Property Prediction with Graph Featurization and Heterogeneous Ensemble Models

This repository contains an implementation of the methods described in the paper:

**"Improving Predictions of Molecular Properties with Graph Featurization and Heterogeneous Ensemble Models"**

**Paper Link:** [https://pubs.acs.org/doi/10.1021/acs.jcim.5c01844](https://pubs.acs.org/doi/10.1021/acs.jcim.5c01844)

**Authors:** Michael L. Parker*, Samar Mahmoud, Bailey Montefiore, Mario Öeren, Himani Tandon, Charlotte Wharrick and Matthew D. Segall
**Journal:** *Journal of Chemical Information and Modeling*, 2025

## Overview

This implementation focuses on improving molecular property predictions through:
- **Graph-based molecular featurization** to represent molecular structure
- **Heterogeneous ensemble models** that combine multiple machine learning algorithms
- Enhanced predictive performance for various molecular properties

## Key Features

- **Graph Featurization**: Conversion of molecular structures into graph representations capturing topological and chemical information
- **Ensemble Learning**: Combination of multiple heterogeneous models (e.g., Random Forest, SVM, Neural Networks) to improve prediction accuracy
- **Molecular Property Prediction**: Application to properties such as solubility, toxicity, bioactivity, and other QSAR/QSPR endpoints
